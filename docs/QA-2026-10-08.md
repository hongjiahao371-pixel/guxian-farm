### 旧存档的处理

保留原有三格存档键。对旧版本可能出现的 `ended=true`、但没有完整日结快照的存档，只补处理尚湿的作物生长，不再次卖货；已干燥并生长过的作物不会再长一遍。此类旧档原本未保存完整出货明细，恢复卡说明进项已计入结余，不编造丢失的明细。

读取另一格存档时，缺失的新字段使用初始默认值，避免沿用上一格的人情、设施或待确认年结。陈酒年份和天气也明确纳入持久状态。

## 验收脚本本身的问题

`dev/run-all.mjs` 原先把 README 中“只跑指定两套”的参数当成排除列表，实际执行其余 37 套；子进程失败或输出 `FAIL` 后，汇总进程仍然以 0 退出。这两个问题已修复，新增显式 `--skip`，错误参数在任何套件启动前拒绝。

另外两处旧断言被修正：`shoot-solar.mjs` 不再把跨年后的 146 日当作正确答案；`shoot-furn.mjs` 中关于读档料理次数的常量 `true` 被真实保存、续档和状态检查替代。

## 仍需实际体验确认的部分

触屏入口还有明确缺口：点击商人目前只会说话，商店主要由 B 键打开；行囊、出货箱、诗册也缺少对应的触屏按钮。纯触屏玩家因此无法完整操作买种、买镐和出货流程。这个结论来自入口代码与事件路径检查，尚未进行手机实机验证，界面补充未纳入本次修复。

下一轮浏览器验收应优先检查：新局耕种到首收的完整流程、刷新与三格存档往返、睡觉和年结确认、真实键鼠与触屏的面板操作，以及窄屏排版、背景音乐和长时间运行的流畅度。

## 启动

下载修复分支后，直接用浏览器打开 `index.html`；也可在项目目录运行：

```bash
python -m http.server 8000
```

随后打开 <http://localhost:8000>。固定使用同一个浏览器、同一个地址，以便继续使用同一份本地存档。
